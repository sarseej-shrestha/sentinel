# Sentinel

Sentinel is a human-approved, read-only supply-chain operations console for CMPS 4200 HCI. The executable demo uses synthetic data only. Phase 2 implementation is in progress on `phase2-coding`.

No real company claims, healthcare data, external actions, autonomous purchasing, shipping or supplier changes, voice interface, general chat, or training a language model from scratch are included. Presentation and visual-design deliverables are outside this coding pass.
